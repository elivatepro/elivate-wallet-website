# Elivate Wallet website — agent notes

Astro marketing site + docs for elivatewallet.com, deployed as a Cloudflare Worker
(`wrangler.jsonc`, `worker/`) from `main` via Workers Builds.

- **Docs content lives in Notion, not in this repo.** `src/content/docs/` and
  `public/docs-media/` are generated by `scripts/sync-notion-docs.mjs`. To write or update
  docs, follow `.claude/skills/elivate-docs/SKILL.md`.
- The blog is also Notion-backed (`scripts/sync-notion-blog.mjs`).
- Secrets (`.env`, `.dev.vars`, Worker secrets, deploy-hook URLs) never go in Git, chat,
  logs or page content.
- Product facts come from the app repo (`elivatepro/elivate-wallet`); never invent product
  behaviour in copy or docs.
